# БДЗ по теории игр — Вариант 29

**Тема:** Кибербезопасность — пентест vs. патч-менеджмент

Модель противостояния независимых пентестеров (игрок A) и службы информационной безопасности платёжного сервиса (игрок B).  
Выигрыш пентестеров — количество захваченных систем и данных (флагов).

## Что есть в репозитории

- **bdz_v29.pdf** — готовый документ с полным решением БДЗ. Внутри:
  - постановка задачи и платёжная матрица с обоснованием всех элементов;
  - анализ доминирования стратегий;
  - проверка седловой точки;
  - графоаналитический метод (вывод формул и оптимальных вероятностей);
  - симплекс-метод (линейное программирование);
  - метод Брауна–Робинсон (таблица итераций и сходимость);
  - итоговые оптимальные стратегии.

- **graph.html** — интерактивное веб-приложение с графиком. Показывает:
  - красную прямую (выигрыш, если защита использует только B₂ — тренинг);
  - синюю прямую (выигрыш, если защита использует только B₃ — WAF);
  - зелёную ломаную — нижнюю огибающую (гарантированный выигрыш);
  - чёрную точку — оптимальное решение (p = 0.375, v = 18.625).
  График можно масштабировать колёсиком мыши, двигать левой кнопкой и сбрасывать масштаб.

## Результаты

- **Цена игры:** 18.625 флагов.
- **Оптимальная стратегия пентестеров (A):**
  - A₁ (атака через API) — 3/8 (37.5%);
  - A₂ (социальная инженерия) — 5/8 (62.5%).
- **Оптимальная стратегия защиты (B):**
  - B₁ (патч API) — 0%;
  - B₂ (антифишинговый тренинг) — 3/8 (37.5%);
  - B₃ (обновление WAF) — 5/8 (62.5%).
